# PikPak / Web 分享链接搜寻

## 方法（两步，别绕）
1. **web_search 直接拼 PikPak 域名**：
   - `系列名 mypikpak.com/s/`
   - `系列名 合集 pikpak 网盘 下载链接`
2. **论坛/频道兜底**：南+（south-plus.net，正规版块需登录，浏览器无凭证进不去）、xsijishe、bbs.dyyjv.com（短剧区）、pikshare.bilivo.top（专门 PikPak 聚合站）。

## 判定与给法
- `mypikpak.com/s/VOxxxx` 即分享链接，标题含合集名/集数/大小。
- **优先给合集链接**（"XXX 作品整理合集 40V 39G"），单集补最新期。
- 链接可能失效（"Files have been deleted"）→ 多搜镜像，标注失效的。
- 直接列链接表（合集/单集分栏），别只描述。

## 注意
- 用户零容忍漏抓/敷衍：要覆盖全（多换关键词、合集+单集都给）。
- 南+ 正规版块需用户自己账号，让用户贴链接给你即可。
- 链接形态：`https://mypikpak.com/s/<ID>` 或带子目录 `/s/<ID>/<subID>`。
