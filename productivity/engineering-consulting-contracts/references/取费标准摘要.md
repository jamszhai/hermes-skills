## 核心计算公式

```
工程设计收费 = 基本设计收费 + 其他设计收费 + 设计总体协调收费
基本设计收费 = 基本设计收费基准价 × (1 ± 浮动幅度值)
基本设计收费基准价 = 基本设计收费基价 × 专业调整系数 × 工程复杂程度调整系数 × 附加调整系数
```

## 既有建筑安全隐患消除设计（导则3.2.5.1）

适用于房屋结构改造加固（含消险设计）：

- **结构安全消险设计**：基本设计收费基准价 × **附加调整系数 1.3~1.6**
- **结构安全评估**（单独委托）：
  - 公共建筑 < 2万㎡：18万元起
  - 居住建筑 < 2万㎡：15万元起
  - 超过上述面积按档递增

## 既有建筑消防专项改造（导则3.2.5.7）

适用于城市更新既有建筑消防改造设计：

- **消防改造设计修正系数**：1.1~1.3
- **消防安全评估**（单独委托）：
  - 公共建筑 < 2万㎡：12万元起
  - 居住建筑 < 2万㎡：8万元起
  - 超过上述面积按档递增
- **消防消险设计修正系数**：1.5~1.8

## 特殊消防设计（导则3.2.3-7/3.2.3-8）

城市更新场景下触发超规范消防设计时适用：

- **收费基价**：60万元
- 按用地规模及审批级别/历史风貌类型系数调整
- 附加论证、模拟、实施后评估另计

## 设计第三方技术咨询（导则3.5.1，表3.5.1）

适用于设计文件审核/第三方技术咨询：

```
设计第三方技术咨询费 = 工程设计收费 × 5%~10%
```

当工程设计收费 ≤ 50万元时，按5万元计取。
