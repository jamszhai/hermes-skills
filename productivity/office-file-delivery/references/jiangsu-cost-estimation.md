# 江苏 / 镇江 建设工程造价指标锚点（查证收集）

> 用于小区规划 / 房地产项目成本测算。仅作测算基准，非官方逐城发布值；实际应以当期信息价与立项批复为准。

## 关键概念区分（易混）
- **"二星成品房"装修** = 江苏《成品住房装修技术标准》舒适型全装修（地墙顶+厨卫全套+固定柜体+灯具，不含家具家电）。镇江三线城市取 **1,200–1,800 元/m²**，中值 1,500。
- **"绿色建筑二星"** = 绿建星级，增量成本仅约 +120 元/m²。两者完全不同，不要混淆或合并。

## 房屋建筑（毛坯建安）锚点
- 省内发达地区住宅建安成本参考指标（2021，基于《江苏省计价表》，剪力墙）：
  - 7–17 层毛坯 **3,160–3,980 元/m²**（土建 2,250–2,450 + 安装 330–400）。
  - 地下连通车库：非人防 **3,200–4,100**；人防 **4,100–5,200 元/m²**。
  - 桩基 / 基坑围护 / 土方：按总建面另计 **230–490 元/m²**。
- 酒店单方：毛坯建安约 4,200 元/m²（公区/机电/消防标准高于住宅）；若按四星精装运营，建安+精装可达 **8,000–12,000 元/m²**（单酒店项或增 5,000万–1.1亿）。
- 凯谛思/RLB《2024 中国造价信息汇编》：中档高层公寓精装 23,000–26,500 HKD/m²（含全配，作酒店上限参照）。

## 室外配套（市政附属）
- 实测锚点：安置房招标"小区市政配套 200 元/m²（建面）"。综合取约 **250 元/m²（按总建面）**。
- 构成：道路硬化（~250 元/m²）、室外管网（按用地 ~400 元/m²）、围墙/大门/门卫、路灯/智能化/标识/环卫、生化池/隔油池等（后几项常按"项"估算）。

## 室外景观（高档）
- 行业公认高档小区景观 **300–600 元/m²（按景观面积）**，中值 500。
- 注意：规划指标只给"绿地面积"，高档景观实际覆盖 = 集中绿地 + 宅间 + 入口 + 水景，常远大于绿地面积（本项目按可开发用地扣建筑占地与车行道估算约 11,000 m²，属估算、敏感）。

## 地域修正
- 镇江属江苏三线城市，人工材料较省内发达地区低约 **8–12%**，省级指标取中值并适度下浮。
- 口径：测算多为"建造毛坯+装修成本"，不含土地、前期/设计/监理、管理费、财务、营销、税金利润；加土地与完全成本典型商品房全成本约 **7,000–12,000 元/m²**。
