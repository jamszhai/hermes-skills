# 地产开发项目成本测算（江苏/长三角均价）

## 何时用
- 用户给出小区/地块经济技术指标，要求"成本测算/造价估算/投资估算"。
- 要求按 房屋建筑、室外配套、室外景观 等分部分项列成本。
- 涉及"成品房/全装修/二星成品房"装修费单列。
- 镇江/江苏/长三角 的房地产开发成本测算。

## 工作流程

### 1. 核实指标（图片先用 vision_analyze）
用户贴的规划指标表常为图片。先用 vision_analyze 逐行精确读出 项目/单位/数值/备注，并与用户文字核对。必做勾稽校验：
- 总建面 = 计容建筑面积 + 不计容建筑面积 + 地下室建筑面积
- 计容 = 住宅 + 商业 + 酒店 + 配套 + …
若对不上，向用户确认，不要硬凑。

### 2. 查证基准单价（禁止瞎估，先查再算）
用 web_search / web_extract 找权威锚点（优先级从高到低）：
- **苏州住宅建安成本参考指标**（苏州市造价管理处，基于《江苏省计价表》）：7–17层剪力墙毛坯 3,160–3,980 元/m²；地下连通车库非人防 3,200–4,100、人防 4,100–5,200；桩基/基坑/土方按总建面另计 230–490 元/m²。
- **南京建凯《省会城市住宅建安工程造价指标》**：江苏最权威区域基准（正文常在内网，可能被拦截，取入口确认 + 苏州指标兜底）。
- **凯谛思(Arcadis)/RLB《中国造价信息汇编》**：中档高层公寓精装 23,000–26,500 HKD/m²（含全配，作酒店上限参照）。
- 室外配套：实测招标"小区市政配套 200 元/m²(建面)"可作上限；综合取 200–300。
- 景观：行业公认高档小区 300–600 元/m²(景观面积)。
镇江属江苏三线，人工材料较苏锡宁低约 8–12%，省级指标取中值并适度下浮。详见 references/jiangsu-cost-benchmarks.md。

### 3. 分层测算（四大块，装修单列避免重复）
1. **房屋建筑（毛坯建安）**：住宅/商业/酒店/配套/地下室 + 桩基+基坑+土方（后三项以总建面为基数）。
2. **室外配套**：道路硬化、室外管网、围墙大门、路灯智能化、生化池等。综合≈250 元/m²(建面)。
3. **室外高档景观**：以"景观面积"为基数（不是绿地面积！见 Pitfalls）。
4. **专项装修（单列）**：如二星成品房装修，仅住宅计，与①毛坯建安不重复。

### 4. 生成 Excel（公式驱动，单价可改自动重算）
用 openpyxl 生成多工作表：
- 测算汇总（各分表合计自动求和 + 单方/占比）
- 1-房屋建筑 / 2-室外配套 / 3-室外景观 / 4-专项装修（各明细）
- 依据与假设（列出所有单价锚点 + 哪些是估算⚠️）
合价统一用公式 `=工程量*单方/10000`（万元）。保存前设 `wb.calculation.fullCalcOnLoad=True` 确保任何打开方式都重算。详见 scripts/make_cost_xlsx.py。

### 5. 交付时附"依据与假设"
明确标注：哪些是查证锚点（苏州/南京建凯/凯谛思），哪些是估算（⚠️ 非官方发布值：镇江下浮系数、酒店毛坯口径、景观面积认定、二星装修单价）。

## Pitfalls（必读）
- **二星成品房 ≠ 绿色建筑二星**。搜索里"二星+120元/m²"是绿建星级增量成本，不是装修费。二星成品房按《江苏省成品住房装修技术标准》舒适型全装修（地墙顶+厨卫全套+柜体+灯具，不含家具家电）。镇江三线城市取 1,200–1,800 中值 1,500 元/m²（估算）。向用户确认实际精装标准，高档可到 2,000–3,000。
- **毛坯建安与户内装修不能重复计**。装修单列时，①只算毛坯（含基本公区简装+基本机电消防）。
- **酒店口径差异巨大**：毛坯建安 4,000–4,500 vs 四星精装运营 8,000–12,000 元/m²，单项可差 5,000万–1.1亿。必须确认。
- **景观面积认定**：图片只给"绿地面积"，高档景观=集中绿地+宅间+入口+水景，远大于此。按可开发用地扣建筑占地与纯车行道估算，并做敏感性（9,000→450万 / 12,000→660万）。
- **汇总占比分母**：指向合计行，错一行会除零报错。
- **execute_code 被拦截**（未授权）：改用 write_file 落脚本 + terminal 运行，效果相同。
- 本测算是"建造成本（毛坯+装修）"，不含土地/前期/管理费/财务/营销/税金利润。加土地全成本约 7,000–12,000 元/m²。
