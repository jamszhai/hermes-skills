# Architecture Design Institute Risk Scope Reference

> Session finding: comprehensive risk lists for 建筑设计院 must be authority-scoped.

## Org authority model for group subsidiary 建筑设计院

| Authority | Status |
|---|---|
| 独立法人 / 财务核算 | 否，集团统一管控 |
| 人事权 | 否，集团人力资源部统一管理 |
| 项目承接/设计质量管理 | 是，核心业务 |
| 印章/资质证照使用 | 是，院内专管 |
| 分包/外协选择 | 有限，金额审批分级 |
| 设计费收取 | 院内催收 + 集团财务执行 |

## EXCLUDE for non-independent finance/HR orgs

- 财务报销与经费管理
- 固定资产与办公采购
- 人事招聘与职称评审
- 薪酬与绩效分配

## Typical 11-item design-institute risk set

**High**: 项目投标与承接 / 设计成果质量与校审 / 印章与证照管理 / 项目分包与外协 / 项目变更与洽商 / 合作单位公关与业务拓展

**Medium**: 业务招待与礼品管理 / 涉密项目与知识产权 / 考勤管理与劳动纪律 / 信息化与数据管理

**Low**: 行业协会与社会组织兼职
